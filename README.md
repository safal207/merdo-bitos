# Merdo × BitOS — Social Fashion Pilot

Независимое **демо-концепт** приложение для предложения сотрудничества магазину Merdo. **Неофициальный сайт**: Merdo не подтверждал партнёрство.

## Что реализовано

- RU / TR интерфейс и адаптивная фотолента: просмотры, лайки и кнопка «поделиться»
- Демонстрационные подборки образов (визуальные идеи, не подтверждённый каталог Merdo)
- **«С чем носить?»**: три кадра на одной иллюстративной фотографии — общий образ, детали, состав комплекта
- **My Wardrobe**: пять категорий вещей; при необходимости можно указать цвет, фасон и добавить свою фотографию. Выбор и сжатые изображения сохраняются локально в браузере, без аккаунта и отправки на сервер.
- **4 шага к образу**: цель → посадка → бюджет → необязательный портной
- **BitOS Personal Stylist**: повод, силуэт, посадка, обувь, бюджет и рекомендации по комплекту
- **Perfect Fit**: опциональная подгонка у портного с отдельной *условной* сметой
- Запрос на примерку / информацию: только копирование текста, **без отправки и бронирования**

## Границы демонстрации

Нет реальных цен, ассортимента, остатков, внешнего сервера, официального WhatsApp API, подтверждённого портного или записи на примерку. Стоимость подгонки в интерфейсе условная и используется только для иллюстрации UX.

Счётчики просмотров и реакций локальные для конкретного браузера; они не отражают общий спрос или продажи. Изображения — иллюстративные фотографии, не товары Merdo.

**Мой гардероб** хранит локально отметки категорий, выбранные вручную цвета и фасоны, а также необязательные уменьшенные фотографии (JPEG/WebP) в `localStorage`. Исходный загруженный файл не отправляется ни на сервер, ни в сообщение магазину. Фотография сжимается через Canvas; оригинальные EXIF-метаданные не сохраняются. Пользователь может удалить фото отдельно или очистить весь гардероб. Локальные данные могут быть потеряны при очистке браузера; не следует использовать это как единственное хранилище важных фотографий.

Стилист показывает цвета и фасоны, **указанные пользователем**, и осторожные цветовые идеи по фиксированным правилам. Распознавания изображений и подтверждения сочетаемости пока нет. Уже имеющиеся категории не предлагаются к повторной покупке; освободившийся бюджет не перераспределяется.

## Локальный запуск

```bash
python3 -m http.server 8000
# http://localhost:8000/
```

## Качество и публикация

Файл `.github/workflows/pages.yml` проверяет синтаксис и прогоняет Playwright smoke (мобильный/десктоп) перед деплоем Pages. После успеха публикуется **https://safal207.github.io/merdo-bitos/**.

Если GitHub Pages не включены, перейдите в **Settings → Pages → Build and deployment → Source: GitHub Actions**. Не отключайте тесты ради публикации.
