# Trust & Communication Engine 8.9
Experimental synthetic reducer and composition, not client-facing. Research: TRUST-COMMUNICATION.md, hypotheses H11–H14. Explicit permission, stated need, reflection, confirmation/correction, curated dated evidence, optional support, voluntary decision. Stop or decline at any stage; restart explicitly with new revision. Correction invalidates decision and evidence display. Unknown availability cannot become scarcity. No free-text customer identifiers, trust score, inferred motive, psychological profile, purchases, CRM, analytics, pricing or automated messages.
Learning/activation are independent objects changed only by explicit domain events; stop blocks both routes. Learning requires explicit reset after a communication restart, even for the same topic. Evidence disclosure persists within the synthetic session to prevent contaminated independent assessments: exposed contexts cannot start independent or transfer tasks; in-flight tasks require explicit assisted feedback. No claim of empirical learning gain, trust or revenue. Synthetic intensity only appears for matching confirmed need in active session, never as a measure of a real person. Evidence registry reflects dated technical observations, not live availability. Tests run via node scripts/atelier23-trust-communication.mjs. No UI integration.
